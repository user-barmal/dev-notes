# dev-notes

This repository contains my notes on various engineering topics I've worked
on across different projects.

There's already a lot of verbose documentation for most of this stuff
online, so why bother? Because that documentation is usually general,
and I often need to find something I've *already* worked through before.
These notes let me take a quick peek at things I've solved in the past,
instead of digging through the same threads and pages over and over again.
They also show the range of things I've had to work with while solving
the various issues I've run into.

Since a lot of this comes from day-to-day work with things like Linux,
these notes tend to cover the kind of everyday, practical usage you run
into repeatedly, rather than deep dives into specialized or edge-case
topics. If you also use these tools in your daily work, there's a good
chance you've needed very similar notes yourself, so this might save
you some time too.

Feel free to take a look, fork it, and make your own notes out of it. 
Just keep a note about why it was created in the first place.

If you spot any issues, contributors are more than welcome.
